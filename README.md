## 🏗️ 现代技术栈 (The Stack)

> 2025年的一人公司标准架构，主打“快”与“稳”。

### 1. 全栈框架
- **[Next.js 15](https://nextjs.org/)**: 依然是 React 生态的王者，Server Components 让全栈开发更简单。
- **[Remix](https://remix.run/)**: 更加注重 Web 标准，上手心智负担较小。

### 2. 后端与数据库 (BaaS)
- **[Supabase](https://supabase.com)**: 开源 Firebase 替代品。提供 Auth、Database (PostgreSQL)、Storage、Edge Functions。一人公司首选。
- **[Convex](https://www.convex.dev/)**: 真正的新一代后端，类型安全到了极致，无需手动管理数据库 Schema。

### 3. 部署与运维
- **[Vercel](https://vercel.com)**: 前端部署首选，零配置上线。
- **[Zeabur](https://zeabur.com)**: 国人开发，对全栈应用（如 Next.js + Docker 数据库）支持极好，服务器在很多区域可选。
- **[Coolify](https://coolify.io)**: 如果你有闲置 VPS，用它来自建 PaaS，省下昂贵的云服务费。
