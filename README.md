## 💡 Phase 1: 灵感与验证 (Ideation & Validation)
> **目标**：在写第一行代码前，确认有人愿意买单。

| 排名 | 工具 | 核心用途 | 推荐理由 |
| :--- | :--- | :--- | :--- |
| 👑 | **[Perplexity](https://www.perplexity.ai)** | 市场调研 | 代替 Google。快速搜索“xx痛点目前的解决方案”，分析竞品优劣势。 |
| 🥈 | **[GummySearch](https://gummysearch.com)** | Reddit 挖掘 | 专门用于在 Reddit 寻找用户痛点，发现没人解决的真实需求。 |
| 💎 | **[Google Trends](https://trends.google.com)** | 趋势验证 | 免费。确认你的关键词是处于上升期还是衰退期。 |
| 🛠️ | **[Carrd](https://carrd.co)** | 落地页验证 | 10分钟做一个单页 Landing Page，挂上 Waiting List，测试转化率。 |

## ⚡ Phase 2: 极速开发 (AI Development Stack)
> **目标**：MVP (最小可行性产品) 开发周期从“周”缩短到“小时”。

### 💻 AI IDE (编辑器) 排名
*2025年是 AI IDE 的战国时代，选择适合你的。*

- **👑 冠军: [Cursor](https://cursor.com)**
    - **核心功能**: Composer (多文件编辑)。
    - **评价**: 目前生态最成熟，对项目全局理解最深。配合 Claude 3.5 Sonnet 是当前最强组合。
- **🥈 亚军: [Windsurf](https://codeium.com/windsurf)**
    - **核心功能**: Cascade (深度上下文感知)。
    - **评价**: 后起之秀，不仅能写代码，还能“阅读”你的终端输出并自动修复错误，体验极丝滑。
- **🥉 季军: [Trae](https://www.trae.ai/)**
    - **评价**: 字节跳动出品，免费且支持中文，适合国内网络环境，集成 DeepSeek 等模型。

### 🚀 全栈生成工具 (No-Code / Low-Code)
*如果你不想配置环境，直接在浏览器里把 App 做出来。*

- **👑 [Bolt.new](https://bolt.new)**: StackBlitz 出品。一句话生成 Next.js/Remix 全栈应用，直接部署。
- **🥈 [Lovable](https://lovable.dev)**: 能够生成更高质量、更接近生产环境的代码，支持 Supabase 无缝集成。
- **🛠️ [v0.dev](https://v0.dev)**: Vercel 出品。专注于生成 React/Tailwind UI 组件，前端切图杀手。

### 🧠 核心大模型选择
- **逻辑编程**: `Claude 3.5 Sonnet` (目前公认写代码逻辑最好)
- **复杂推理**: `OpenAI o1` / `DeepSeek-R1` (处理复杂算法或架构设计)
- **极致性价比**: `DeepSeek-V3` (API 价格极低，适合高频任务)

## 🏗️ Phase 3: 基础设施 (Infrastructure)
> **目标**：零运维 (NoOps)，免费起步，按量付费。

| 组件 | 👑 首选工具 | 🥈 备选方案 | 备注 |
| :--- | :--- | :--- | :--- |
| **后端服务 (BaaS)** | **[Supabase](https://supabase.com)** | **Convex** | Supabase 是 Firebase 的开源替代，包含数据库、Auth、API。Convex 开发体验更现代。 |
| **前端托管** | **[Vercel](https://vercel.com)** | **Cloudflare Pages** | Vercel 体验最好；Cloudflare 更加便宜且全球速度快。 |
| **全栈部署** | **[Zeabur](https://zeabur.com)** | **Railway** | Zeabur 对国人开发者极其友好，价格透明；Railway 也是老牌稳定之选。 |
| **自建 PaaS** | **[Coolify](https://coolify.io)** | **Dokku** | 如果你有闲置 VPS，装一个 Coolify，你就有了自己的 Vercel。 |

## 🎨 Phase 4: 设计与交互 (Design & UX)
> **目标**：让产品看起来像出自专业团队之手。

- **Logo & 矢量图**: **[Recraft](https://www.recraft.ai)** (👑 2025最佳)
    - 唯一能生成完美矢量图(SVG)和图标的 AI，风格可控性远超 Midjourney。
- **UI 截图美化**: **[Pika](https://pika.style)** / **Ray.so**
    - 即使你的 UI 很丑，套上这些壳子也会变得很专业。
- **流程图/示意图**: **[Napkin.ai](https://napkin.ai)**
    - 输入文字文档，自动生成专业的解释性图表，非常适合做 Landing Page 的插图。

## 💰 Phase 5: 全球收款与公司架构 (Payments & Legal)
> **目标**：合规地把钱收进口袋，处理全球税务。

| 排名 | 工具 | 适用场景 | 关键优势 |
| :--- | :--- | :--- | :--- |
| 👑 | **[Lemon Squeezy](https://www.lemonsqueezy.com)** | 数字产品/SaaS | **MoR (Merchant of Record)**。它替你处理全球各地的增值税/消费税，这点对一人公司至关重要。 |
| 🥈 | **[Stripe](https://stripe.com)** | 任何场景 | 行业标准，API 最强。但需要自己处理税务合规（或集成 Stripe Tax）。 |
| 🛠️ | **[Doola](https://doola.com)** | 开设美国公司 | 帮非美国居民注册美国 LLC、申请 EIN 税号和银行账户，一人公司出海标配。 |

## 📣 Phase 6: 营销与增长 (Marketing & Growth)
> **目标**：Build in Public，获取自然流量 (SEO)。

### 演示视频制作
- **👑 [Screen Studio](https://www.screen.studio)** (Mac): 录屏神器。自动缩放鼠标焦点，自动平滑动画。哪怕你的操作很生硬，它录出来也像苹果官方宣传片。

### SEO 与内容
- **[Ahrefs Webmaster](https://ahrefs.com/webmaster-tools)**: 免费版足够一人公司使用，监控网站健康和关键词。
- **[Opengraph.xyz](https://opengraph.xyz)**: 检查你的链接在 Twitter/Facebook 分享时的预览图是否好看。

### 社交媒体管理
- **[Typefully](https://typefully.com)**: 专门写 Twitter/X 的工具，支持定时发送和数据分析。
- **[Hypefury](https://hypefury.com)**: 自动转发老推文，保持账号活跃度。

## 🤖 Phase 7: 自动化与运营 (Operations & Automation)
> **目标**：把重复性工作交给机器人。

- **工作流自动化**:
    - **👑 [Make.com](https://www.make.com)**: 比 Zapier 更直观、更便宜，可视化拖拽逻辑。
    - **场景**: 用户付款 -> 发送欢迎邮件 -> 加入 Discord 群组 -> 记入 Notion 数据库。
- **客户支持**:
    - **[Crisp](https://crisp.chat)**: 免费版很好用的网页聊天插件。
    - **[Intercom Fin](https://www.intercom.com/ai-bot)**: 如果预算充足，AI 客服能拦截 80% 的基础问题。
- **个人知识库**:
    - **[Notion](https://notion.so)** / **[Obsidian](https://obsidian.md)**: 管理任务、文档和灵感。
